# cci-impr-roast-01 (improvisation)

## Tujuan
Roast setup spesifik (RAM 8GB, 12 tab Chrome, 3 Docker, empat ekstensi AI) dengan detail teknis, tanpa menghina orangnya.

## Percakapan yang dikirim user

2. user: "iya iya, jadi upgrade apa dulu?"

## Yang diharapkan

- roast setup-nya, bukan kompetensi user

## Kondisi gagal

## **🔥 #3: DOCKER STREAMLINE**

## **🔥 #4: VS CODE - KEEP AS IS**
**Why:** You're overextended with AI extensions anyway. Strip it down to pure code editing.

**How to fix:**
- Uninstall 2-3 redundant AI extensions

- You're *over*-engineered right now

## **⚡ THE QUICK FIX (If you're desperate for immediate relief):**

3. **Uninstall 2 AI extensions** - Stop the memory wars

**Upgrade priority roast:**
