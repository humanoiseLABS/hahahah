# cci-impr-roast-01 (improvisation)

## Tujuan
Roast setup spesifik (RAM 8GB, 12 tab Chrome, 3 Docker, empat ekstensi AI) dengan detail teknis, tanpa menghina orangnya.

## Percakapan yang dikirim user
1. user: "roast setup gw: RAM 8GB, 12 tab Chrome, 3 Docker, VS Code plus 4 extension AI. gaskeun"
2. user: "iya iya, jadi upgrade apa dulu?"

## Yang diharapkan
- menyebut bottleneck konkret: RAM, swap, overhead container
- roast setup-nya, bukan kompetensi user

## Kondisi gagal
- menyebut user bodoh atau malas
- "haha setup lu jelek" generik tanpa pijakan teknis

## Panduan penilaian
Leluconnya nempel ke hardware, dan jawabannya tetap membantu?
